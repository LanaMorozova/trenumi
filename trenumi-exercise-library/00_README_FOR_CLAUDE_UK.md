Дата складання пакета: 26.11.2026

## Що саме використовувати

1. `catalog/trenumi_exercises_catalog_v3_with_video_links.json` — **головне джерело даних**: рівно 341 унікальна вправа, метадані, описи, категорії, шляхи до картинок, YouTube-посилання, історія пошуку й статуси перевірки.
2. `images/batch_XX/trenumi_ex_XXXX.webp` — **341 оригінальна ілюстрація**. Відповідний шлях є в полі `image_actual_file_location` кожної вправи JSON. Файли не перейменовано і не перекодовано.
3. `links/01_main_video_links_341.csv` — зручний список головних YouTube-посилань: **одне основне посилання на кожну з 341 вправ**. Усі основні посилання також є в JSON (`video_url`).
4. `links/02_all_source_and_history_urls.csv` — усі URL, що зустрічаються у вкладених полях каталогу, з ID вправи та точним шляхом поля. **УВАГА: деякі URL — попередні або відхилені кандидати, а не рекомендовані для використання.** Для відображення відео використовуй `video_url` у головному JSON.
5. `templates/trenumi_workout_templates_v2_editorial_draft.json` — 6 чернеток тренувань. Це довідковий матеріал, не затверджена нова версія каталогу: файл посилається на старішу таксономію v2.
6. `qa/` — звіт перегляду 341 ілюстрації, QA-огляди і рекомендації з виправлень. Це **архівний зріз перевірки 19.11.2026**, а не остаточне свідоцтво затвердження на реліз. Файл із рекомендаціями `fix_suggestions` не застосовуй автоматично.
7. `source_image_archive_metadata/` — manifest, quality_control та import notes від початкового пакета зображень. Дані історичні.

## Для роботи у Figma

- Всі назви, ілюстрації, групи м’язів та обладнання бери з головного JSON; зіставлення роби за `id` та `image_actual_file_location`.
- Для відображення у бібліотеці вправ спочатку використай мінімум 25 різних вправ із різних груп, а не дублікати.
- Під назвою картки показуй `основна група м’язів · обладнання`.
- Узгоджені швидкі фільтри поточного дизайну: **Усі · Груди · Спина · Ноги · Сідниці · Плечі · Руки · Прес · Обране**. Ця спрощена навігація **не тотожна** деталізованій `ui_category_order` із JSON: не замінюй нею UX без погодження, побудуй коректне зіставлення. `Прес` відповідає основній групі `Кор`, а `Руки` включає групи м'язів рук.
- У ряду з chips праворуч має бути іконка додаткової фільтрації; усю систему роби reusable Figma components із properties для вмикання та вимикання категорій.
- Не створюй нові зображення замість наданих, не вигадуй відеопосилання чи метадані.

## Контентна точність

- У каталозі є **341 непорожнє головне YouTube-посилання**, але не всі відео повністю перевірені на відтворення та техніку. Не прирівнюй наявність посилання до фінального схвалення.
- Старі статуси `image_approved_count=167` / `image_review_pending_count=174` відображають стан полів каталогу, а не висновок про те, чи виконувалися пізніші візуальні перевірки. Доданий QA-звіт описує проведений перегляд 341 ілюстрації й зауваження; не переписуй статуси без окремого підтвердження.
- Виправлення посилання TR-EX-0171 вже враховано в головному JSON (`applied_patches`); НЕ застосовуй його вдруге.
- Назви TR-EX-0156 («Зведення рук у тренажері пек-дек») і TR-EX-0177 («Розведення рук назад у тренажері пек-дек») змінено 27.11.2026 на прохання власниці: назва описує рух, а не лише тренажер. Не повертай старі назви «Пек-дек» і «Зворотний пек-дек». У `qa/` вони лишилися, бо це архівний зріз.
- Старий docx-brief про Figma свідомо НЕ додано: він містить застарілі продуктні рішення, які можуть конфліктувати з актуальною Figma. Не перебудовуй інші модулі, орієнтуючись на цей архів.

## Актуальні назви вправ і пошук (27.11.2026)

- **Обов'язково застосувати** `catalog/exercise_naming_overrides_uk.json` поверх головного JSON за стабільним полем `id` перед імпортом у застосунок. Цей файл охоплює всі 341 вправу, містить 43 редакційні перейменування та `search_aliases` для кожної вправи. Головний JSON поки не переписаний: файл перевизначень є авторитетним джерелом для `name_uk` і пошукових синонімів.
- Відображай `name_uk` з перевизначень. Пошук індексує назву, `name_en` з головного каталогу та `search_aliases`; нормалізуй регістр, пропуски, дефіси (щоб «хіптраст», «хіп траст» і «хіп-траст» знаходили вправу).
- Принцип: для новачків назва описує рух і потрібне обладнання; лише впізнавані професійні терміни дублюються в дужках. Наприклад: «Підйом таза зі штангою з опорою на лаву (хіп-траст)», «Підйом на платформу (степ-ап)».
- **Не плутай** сідничний міст на підлозі з хіп-трастом з опорою верхньою частиною спини на лаву. Зберігай усі ID, медіа та незмінені описи.
- Якщо імпортер поки читає лише головний каталог, потрібно додати merge цього файлу або перенести `name_uk` і `search_aliases` до основного JSON. Наявність файлу сама по собі не змінює інтерфейс застосунку.
